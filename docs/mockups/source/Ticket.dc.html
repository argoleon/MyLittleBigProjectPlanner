Migration de l’authentification vers OIDC

Description

Remplacer l’authentification locale de l’annuaire par OIDC (Entra ID). Les comptes locaux restent disponibles pour les prestataires qui n’ont pas de compte dans l’annuaire de l’entreprise.

Critères d’acceptation

  • Connexion par Entra ID pour tous les comptes internes
  • Repli sur les comptes locaux pour les prestataires
  • Déconnexion propagée vers le fournisseur d’identité
