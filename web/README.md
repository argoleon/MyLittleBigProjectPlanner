# Web

Angular workspace of My Little Big Project Planner: Angular 22, standalone components, signals, zoneless, `OnPush` by default, Angular Material 3.

| Project | Content |
| --- | --- |
| `projects/app` | Internal application: shell with the navigation of the mockups, placeholder screens |
| `projects/portal` | Request portal: top app bar, placeholder home page |
| `projects/ui` | Shared library: theme (`styles/`), translations (`i18n/`), API client, shell, shared components |

Everything runs in the development containers, through `just`, from the repository root:

| Command | Does |
| --- | --- |
| `just dev` | API on :18080 and the internal application on http://127.0.0.1:4200 (`/api` proxied), live reload |
| `just web-lint` | ESLint (with the template accessibility rules) and stylelint |
| `just web-i18n` | Fails if a translation key is missing in `fr.json` or `en.json` |
| `just web-test` | Unit and integration tests (Vitest) of the three projects |
| `just web-build` | Production builds |
| `just web-licenses` | License check of the npm dependencies, on the shipped bundles |
| `just e2e` | End-to-end tests (Playwright, axe-core) in the `e2e` container |
| `just generate-client` | Regenerates `backend/openapi.json`, then the API client |
| `just web-check` | All of the above, as in CI |
| `just npm …` | Any npm command, e.g. `just npm install --save-exact <package>` |

## Building a screen

Read the "Frontend rules" of `CLAUDE.md` first. In short:

- **Shell and navigation**: `ui-shell` takes the `NavItem`s of `projects/app/src/app/navigation.ts`; a route's `title` is a translation key (`TranslatedTitleStrategy` adds the application name).
- **Translations**: Transloco, files in `projects/ui/i18n/` (loaded at runtime, copied into each application). Add every key to both `fr.json` and `en.json`; `just web-i18n` and a unit test check it. The language follows the user's choice, then the browser (`LocaleService`).
- **Dates and numbers**: `instant` (timestamps, shown in the user's time zone), `localDate` (planning dates, never converted) and `localNumber` pipes; pure functions in `ui/src/lib/i18n/format.ts`.
- **Data**: inject the generated `Api` and call its functions; components never use `HttpClient` (an ESLint rule forbids it in the applications). Errors are `ApiProblem`s.
- **States**: `ui-loading-state`, `ui-empty-state`, `ui-error-state` (takes the caught error, offers a retry); labels with `ui-status-chip` and `ui-type-chip`.
- **Styles**: in `.scss` files only (no inline `styles`), using `--mat-sys-*` and `--app-*` tokens; stylelint rejects hard-coded colors, fonts, radii and shadows.
- **Theme**: `ThemeService` (system, light, dark) sets `<html data-theme>`; fonts and icons are self-hosted (`@fontsource/roboto`, `material-symbols`).
- **Tests**: Vitest with `provideI18nTesting()` and `axeViolations()` from `ui/testing`; Playwright in `e2e/` for key flows, with axe-core in light and dark mode.

## API client

`projects/ui/src/lib/api/generated/` is generated by [ng-openapi-gen](https://github.com/cyclosproject/ng-openapi-gen) (MIT) from `backend/openapi.json`, with `ng-openapi-gen.json`. Never edit it by hand: change the Rust annotations and run `just generate-client`.

Hand-written next to it:

- `provide-api.ts`: `provideApi()`, which sets up `HttpClient`, the API root URL, session cookies, and turns error responses into `ApiProblem`;
- `api-problem.ts`: `ApiProblem` and the translation keys of error codes (`errors.<code>`, `errors.field.<code>`);
- `testing/contract-backend.ts`: a mocked backend generated from the contract, for tests.
